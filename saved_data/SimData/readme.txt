This folder contains simulated magnetic field and ODMR data.
Each ODMR file contains multiple ODMR spectra that correspond to the magnetic field/spatial coordinates values in Bdata as the following:

ODMR  -----   Bdata
NV_ODMRsim_Bz0   -----   2cyl_00z
NV_ODMRsim_Bz45   -----   2cyl_00z
NV_ODMRsim_rd20   -----   2cyl_05L_20pt
NV_ODMRsim_rd100   -----   2cyl_05L_100pt
